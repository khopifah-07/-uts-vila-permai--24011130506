## Deskripsi Singkat
Aplikasi pemesanan vila statis berbasis HTML, CSS, dan JavaScript tanpa back-end yang dirancang khusus untuk usaha "Vila Permai" di Puncak, Bogor. Berfungsi memudahkan calon tamu dalam melihat katalog, melakukan perhitungan estimasi biaya otomatis, serta memvalidasi formulir pemesanan.

## Fitur Utama
- [x] Katalog Vila Dinamis (Render array JavaScript menggunakan DOM)
- [x] Fitur Pencarian / Filter Vila berdasarkan kata kunci
- [x] Kalkulasi Total Biaya & Durasi Menginap secara Otomatis
- [x] Validasi Formulir Interaktif dalam Bahasa Indonesia
- [x] Desain Responsif (Dukungan Tampilan Ponsel, Tablet, Desktop)
- [x] Penyimpanan Nama Tamu Terakhir melalui `localStorage`

## Fitur yang Belum Selesai / Pengembangan Selanjutnya
- Integrasi dengan WhatsApp API untuk pengiriman pesan otomatis.
- Sistem kalender interaktif untuk melihat tanggal terisi (booked dates).

## Cara Menjalankan
1. Clone repository ini atau unduh file zip.
2. Buka folder proyek `uts-vila-permai`.
3. Buka file `index.html` langsung pada browser atau gunakan ekstensi Live Server di VS Code.
